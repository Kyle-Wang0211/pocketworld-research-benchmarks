## 问题

E13 证明鬼点活在真点不覆盖的像素无人区(同帧最近真观测 p50=190px,0.5-8px 区间近乎空)。
detector-free / 救援覆盖能不能占领这些无人区,给鬼制造对手?

## 口径

- 鬼带/真带 = E13 step2 固定生产平面口径:ghost [-45,-20)mm、true [-7.5,+12.5)mm(cap51 鬼带含 -32.5~-37.5mm 次峰)。
- 像素空间 = camera 3840×2160(db==images.bin,E13 已逐位验证);E6 f=image_id-1(源码坐实);
  floor_rescue WORK 1024×576 ×3.75 回投,fid→image_id=fid+1 经三帧位姿对拍(最差差 0.080,ARKit vs BA 精化位姿的预期量级,帧身份成立)。
- **可制造对手率** = 鬼带 3D 点其任一观测像素的半径 8/16/32px 邻域内存在覆盖源观测的点占比;
  真带点走同一管道作对照直尺。

## 结果(`analysis/e15_confluence.json`)

### 可及性:无人区不是 detector-free 的沙漠

| 源 × cap | 鬼带 r8/r16/r32 (%) | 真带对照 r8/r16/r32 (%) | 鬼带最近覆盖 p50 |
|---|---|---|---|
| E6 注入点 cap51 | 0.33 / 0.53 / 1.15 | 0.62 / 0.74 / 1.23 | 419px |
| E6 候选池 cap51 | **58.6 / 70.9 / 88.9** | 42.5 / 57.2 / 83.8 | **0.0px(同 keypoint)** |
| E6 注入点 cap50 | 7.7 / 9.0 / 15.0 | 22.2 / 25.1 / 35.8 | 130px |
| E6 候选池 cap50 | 63.3 / 66.4 / 80.2 | 69.3 / 75.5 / 90.5 | 0.0px |
| **LoFTR 原始 cap50** | **16.3 / 37.0 / 53.7** | 17.7 / 42.0 / 63.8 | 12.7px |
| 三源并 cap50 | 71.2 / 80.0 / 92.0 | 77.4 / 88.7 / 97.9 | 0.0px |

- LoFTR 触达鬼区的速率 ≈ 真区的 0.84-0.92 倍(37.0 vs 42.0 @16px)——**像素可及性成立**,
  E13 的"真点无人区"对 detector-free 不是无人区(与"欠召回非物理墙"记忆一致)。
- E6 实际注入点对两带都几乎不覆盖(≤1.2%)——注入选点(墙/holdout 语义)根本不在地板战场,判别力为零。

### 对手身份裁决:覆盖≠对手(`analysis/e15_opponent_depth_identity.json`)

对鬼点邻域内的 E6 候选(自带三角化 floor_h)按深度定身份:

| cap × 半径 | 池覆盖鬼点 | 其中候选深度落**真带**(=真对手) | 其中候选**只落鬼带**(=同伙) |
|---|---|---|---|
| cap51 r8px | 4,124/7,034 (58.6%) | **106 (1.51%)** | 2,007 (**28.5%**) |
| cap51 r16px | 4,989 (70.9%) | **171 (2.43%)** | 2,076 (29.5%) |
| cap50 r8px | 409/646 (63.3%) | 50 (7.74%) | 160 (24.8%) |
| cap50 r16px | 429 (66.4%) | 57 (8.82%) | 153 (23.7%) |

**这是本战的钉子**:SIFT 证据池确实覆盖鬼区(p50=0px,直接共享 keypoint),但覆盖者自己
三角化出来的深度绝大多数还是鬼深度——cap51 只有 1.5-2.4% 的鬼点能等到一个真深度 SIFT 对手,
反而 ~29% 的鬼点只会等来**同伙**(再注入=喂鬼)。同一批低视差像素,SIFT 无论怎么救援,
几何上仍解到同一个错误深度——E13 的"证据内无真值锚"从覆盖侧第三次坐实。

## 判决

1. **可及性:高**(cap50 实测 LoFTR r16=37%/r32=54%,达真带对照的 ~0.9 倍;cap51 无 LoFTR 数据,
   属外推——两 cap 鬼带同病理,置信中高)。鬼区不是 detector-free 够不到的地方。
2. **对手制造力:覆盖本身≈零**。有像素覆盖不等于有真深度对手;SIFT 池的实测证明覆盖者会复读
   同一错误深度。LoFTR 匹配的三角化深度同受低视差几何支配,除非配宽基线选对或深度先验,
   不能假设它天然带真深度(本战无其三角化产物,不妄断)。
3. **覆盖集成优先级:中低(作为杀鬼手段)**。detector-free 集成的价值仍在召回/弱纹理密度
   (已有定案),但**不应以"饿死鬼层"立项**——间接饿死路线在证据上不成立,直接注入还有 29% 概率喂鬼。
4. **深度仲裁维持第一优先**:真对手 = 正确深度的锚,来源只能是每视稠密深度(DR5 carving,
   2.2ms/视已定价,λ≈37.6 覆盖充分)。E15 与 E13 合拢:鬼的终结机制是深度证据仲裁,不是覆盖竞争。
