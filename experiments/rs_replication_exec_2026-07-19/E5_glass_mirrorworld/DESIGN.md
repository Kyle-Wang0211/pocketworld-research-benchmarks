## 0. 问题定义与已定事实

**镜像世界类**(E3 定性):平面玻璃/镜面把室内场景反射成"镜后虚像",虚像**几何自洽**(平面镜虚像与真实场景在多视几何上等价,Whelan SIGGRAPH 2018 一手证明连 RC 也出 [B])。我方实测三热区:

| 热区(cap50) | E2-A 候选量 | E3 出生纪律刀战果 | 定性 |
|---|---|---|---|
| 窗玻璃倒影(墙外长尾) | 112 点 | **0/112(免疫)** | 反射面自身无实体体素 → 走廊遮挡票构造性失效 |
| 钢琴漆/镜面家具后 | 69 点 | 2/69(免疫) | 同上 |
| 缎面被(AMB) | 205 点 | 9/205 | 与真背包在 blocked-hits 证据空间**同分布**,不可分 |
| (对照)地板下反射层 | 161 点 | **161/161 全歼零损** | 已被 E3 地板下常驻反对票解决,**不在本设计范围** |

**两难核心**([E2-A] cluster12):门洞外邻室真货架(Z≈−9.1)与玻璃虚像**同为"场景壳外"**。任何"壳外自动杀"都会误杀真几何——E2-A 误报抽查已实锤(簇级 3/10 FP 含门洞真几何),E3 规格原样阈值杀死背包 17/19、货架 1/15 → FAIL。

**RS 生态的答案**(R_research ⑤,[A]+[D] 合成):RC/RS **从未做自动壳外裁剪**——自动只有整云包围盒(size)或密度盒(density,官方自认只适合转台);镜像世界的消亡 100% 靠人(mask 留洞 / region 摆到墙面 / Lasso+Filter 手删 / 物理遮盖);预览对壳外远点**无淡化/隐藏痕迹**(UNRESOLVED 偏否)。**裁决权=用户的几何盒。**

## 1. 两难正面处理:凭什么区分门洞真货架 vs 玻璃虚像

三条候选判据,逐条诚实评可行性。

### (a) 穿越观测连续性 —— **判死(几何层原理性失效)**

设想:门洞=多帧连续看穿+地板延伸;玻璃=只在反射视角成立。逐项检:

- **走廊遮挡子判据**:E3 已实测证伪——反射面自身几乎无实体体素,虚像点的视线走廊与门洞一样"干净"(窗玻璃 0/112 免疫即此机制)。两者在该证据下**同号**。
- **地板延伸子判据**:被镜像地板欺骗。垂直镜面反射地板,虚像地板高度不变、与真地板共面连续——"开口外有连续地板"对镜面同样成立。
- **多帧几何一致性子判据**:平面镜虚像是**几何自洽**的(等价于镜后真有一个镜像房间),视差、三角化残差、track 生命周期全部与真实场景同分布——这是物理事实(Whelan 一手 [B]),不是工程不足。E2-A 指纹也旁证:n_support=0 比例 trail vs clean 几乎同(0.645 vs 0.654),"无可恢复观测"不是判别指纹。

**结论:纯几何观测层不可区分,(a) 不进任何方案**。虚像唯一物理破绽在**光度/语义层**(菲涅尔衰减、透射叠加、手性翻转文字),那是 detector-free 稠密验证的二期话题(E3 结论 3 同款),且每视 MVS ≈80s 爆 30s 预算判死不进预览(07-19 记忆锚)。

### (b) 镜像对称检测(Whelan 签名)—— **可行为"标记器",不可为"裁剪刀";须离线验证**

机制:假设玻璃平面 π(与墙面共面),把壳外候选簇关于 π 反射;若反射后以高比例落回室内已有几何(kNN 距离小)**且颜色一致**(反射同时复制几何与外观),= 镜像签名。门洞货架反射回室内没有理由恰好几何+颜色双重合。

诚实评估:

| 维度 | 评估 |
|---|---|
| 计算代价 | 极低:候选仅数百点(cap50 全部候选 1,004),墙面 RANSAC + 反射 + kNN + 颜色比对,host 秒级,端上可忽略 |
| 平面假设来源 | 我方已有重力对齐+生产地板平面(ghost_mask.json);垂直墙面 RANSAC 是成熟几何,非自创。⚠️ 玻璃常与墙共面(窗)成立,**独立立镜/斜镜不共面 → 漏检**,如实接受(漏检=维持现状,无害) |
| 已知失效模式 | ①双层玻璃产生偏移虚像(反射后差一个 pane 间距)→ kNN 阈值须容忍或漏检;②部分反射簇(只映出半件家具)→ 重合比例低 → 漏检;③室内几何本就稠密 → 门洞真景反射回来**可能部分撞上真家具** → 误标风险,靠颜色一致性+重合比例双门压制,**必须实测不是想当然** |
| 验证集(现成) | E2-A 已审簇:窗玻璃倒影簇(应命中)vs r12 门洞货架 / r09 背包 / r05 天花(**必须零命中,硬红线**);cap51 弱迁移检验(该场景镜面少,候选多为弱纹理浮点,应低命中——也是特异性检验) |
| 输出语义 | **只产 AMBIGUOUS 标签(sidecar),display 层消费;永不删点**。E2-A 结论逐字:检测器适合当"取证探照灯",不适合直接当裁剪刀 |

### (c) RS 式交给用户画框 —— **主路径,零算法风险,RS-faithful 满分**

- 我方"预览=选区界面"与 RS Reconstruction Area 流程节点**同构**(R_research ⑤-1),方向已对。
- 镜后虚像天然落在墙面之后:用户把框边界拖到墙 → 虚像整块落框外("not considered at all" [A] 逐字)→ 镜像世界灭。
- 门洞货架:用户自己决定要不要邻室——**这正是 RC 官方的选择**(裁决权=几何盒+人),两难被移交而非硬解。
- 零算法、零误杀、零新验证负担。

**裁决:c 为主、b 为辅(display 层标记)、a 判死。**

## 3. 推荐执行序(先零风险,后须验证)

### P0(零风险,立即可排)选区界面补齐 RS 交互 parity
抄 R_research ⑤-2 清单:**初始框 auto 提议**(算法=整云包围盒,桌面 RC [A] 唯一有据;默认框住整云=默认不裁任何点,最保守)+ **Reset area** 兜底 + 固定 2D 视角切换 + 拖边界线 + 点云旋转滑杆;框语义=框外不进交付但留 db、可重画框 re-process。
**验收**:①交互 parity 清单逐项打勾(对照 R_research §1.2/1.4 [A] 条目);②不动框 → 交付 PLY 与无选区基线 SHA 逐位相同(默认零裁剪铁证);③画框 → 框内点全量交付、无降采样,框外点 db 可回溯;④四把尺子对账(框住整云时逐位同基线,自然全过)。

### P1(零风险,纯渲染)选区调整界面的框外淡显
L2 范式,仅在选区调整交互中框外点淡显(不隐藏——Fabbaloo [B] 证 RS 连淡化都不做,我们淡显已是增强,隐藏则背离"如实显示"精神)。
**验收**:淡显开/关交付 PLY SHA 逐位相同(Q7 铁证范式);肉眼 compare.html 同 gauge 确认淡显不误导(禁 Sim3)。

### P2(须验证,离线 spike)镜像签名标记器
按 §1(b) 实现 host 离线版:墙面 RANSAC → 候选簇反射 → kNN 重合比例 + 颜色一致性双门 → AMBIGUOUS sidecar。
**验收(先测量后定阈,不预设命中率)**:①硬红线:E2-A 已审保护簇(r12 货架/r09 背包/r05 天花)**零命中**;②窗玻璃倒影簇命中率如实报告(目标方向高,不预承诺数字);③cap51 特异性检验(弱纹理浮点应低命中);④墙钟报告(host 代理);⑤全程只产 sidecar,不动任何 PLY。任一硬红线 FAIL → 标记器降级为纯研究取证,不进产品。

### P3(须用户签决)AMBIGUOUS 标签进产品 display 层
P2 过验收后,呈报包(逐簇肉眼裁块 + 双 cap 命中/误标表 + SHA 铁证)交用户签决:AMBIGUOUS 点在预览中淡显/着色提示(帮用户"看见该把框拖到哪",辅助 P0 而非替代)。**永不自动删点、永不自动收框**;初始框维持整云包围盒,签名只做提示。
**验收**:用户肉眼批准;开/关提示交付 SHA 逐位相同;禁质量滑杆红线自检(提示是信息展示非质量档位,但 UI 形态须避免做成开关滑杆——做成与 quality 热图并列的着色模式,对齐 Q7 已裁决的着色模式框架)。

**排期外(预登记,不排期)**:光度/语义层虚像验证(detector-free 稠密、手性检测)——E3 结论 3 指名的"不同证据",但 80s/视爆预算判死进预览,仅 finalize 侧远期研究;S-生 出生层扣点重议口(见 §2)。

## 4. 诚实:镜像对称检测是否越过"不盲目创新"线

逐层拆:

1. **方法本身有据可依**:Whelan et al., SIGGRAPH 2018 是发表的一手方法,"虚像关于镜面反射后与真实几何重合"是其核心签名——不是我们自创的启发式。⚠️ 但须如实:**Whelan 原始管线的镜面定位依赖镜框/标记类先验(具体机制本轮未重读原文,标"待核",P2 开工前必须重读原文核实)**;我们的"墙面共面假设替代镜面定位"是**改编增量**,这一段是我们自己的,须靠 P2 验证集背书,不许当成"照抄发表方法"来免检。
2. **RS 没公开用它**:R_research [D] 钉死——RS/RC 生态零自动虚像检测。所以把它做成**自动删除**=既背离 RS-faithful 又踩 E2-A 误杀实锤,**越线**;做成 **display-only 提示 + 用户裁决**=不改变"裁决权=用户几何盒"的 RS 范式,属"成熟核心(选区)+局部创新(提示层)",在工程哲学(70+99>99+40)允许域内。
3. **兜底结构保证越不了线**:P2 硬红线(保护簇零命中)+ P3 用户签决 + SHA 铁证 + 永不动数据——即使标记器完全失败,产品仍有 P0/P1 的完整 RS-faithful 答案,镜像世界照样可灭(用户框到墙即灭)。创新件是可摘除的增量,不是承重墙。

**自检结论:P0/P1 零创新纯复刻;P2/P3 是有发表依据、可摘除、display-only、须签决的局部创新——不越线,但改编增量(墙面共面假设)必须实测背书,并有"Whelan 原文机制待核"一项未闭环。**
