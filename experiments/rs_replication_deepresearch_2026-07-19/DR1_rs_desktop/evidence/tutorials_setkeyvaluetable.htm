Keys and Values

The command-line interface (CLI) of RealityScan allows its users to change various settings of the application with the set or preset command. This command requires a key (identifying the setting you want to change) and a value. The tables below contain keys and value types for the basic settings.
TIP: We recommend to try various settings in the application user interface first, and after that work with these settings in the CLI.
