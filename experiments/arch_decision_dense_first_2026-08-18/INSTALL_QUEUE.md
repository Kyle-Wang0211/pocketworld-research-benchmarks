## ① 快速导出(融合 2.8×,逐字节等价)——风险最低,建议先装

- **证据**:官方 filter.py 76.9s 里 62%(46.6s)是 `[tuple(v) for v in vertexs]` Python
  逐点循环;列赋值构造同一 structured array 后 **PLY 输出 MD5 逐字节相同**,46.6s→0.5s。
  三路 parity(官方整体 / 逐 ref 分解+官方导出 / 逐 ref 分解+快速导出)MD5 全等。
- **改动面**:仅 filter.py 导出段(或我们的融合驱动),不碰任何门/数学。
- **风险**:无(逐字节等价已证)。
- **签决点**:装机窗口(避开拍摄/重训占用);装后按"装机≠生效"验一次真跑。

  实测调度:拍摄期融 109/132,尾部 82 帧 ≈17s;激进首融版首块 t=11(4 源暂定档 t=5),

- **改动面**:纯调度/编排层;融合数学与官方 filter_depth 逐字相同。
- **风险**:①拍摄中显示是"暂定版"(内容会细化)——UX 文案要配合;
  ②尾部账依赖 A16 真机数(A4 打点);③口径铁则:重融判据比**有序**列表、
  选源打分复刻官方 calc_score 的小下标重数语义(occ_i×occ_j 会排错 44% ref 的 top-10)。
