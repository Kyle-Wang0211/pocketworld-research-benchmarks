  逐点循环;列赋值构造同一 structured array 后 **PLY 输出 MD5 逐字节相同**,46.6s→0.5s。
  三路 parity(官方整体 / 逐 ref 分解+官方导出 / 逐 ref 分解+快速导出)MD5 全等。
- **改动面**:仅 filter.py 导出段(或我们的融合驱动),不碰任何门/数学。
- **风险**:无(逐字节等价已证)。
- **签决点**:装机窗口(避开拍摄/重训占用);装后按"装机≠生效"验一次真跑。

- **改动面**:纯调度/编排层;融合数学与官方 filter_depth 逐字相同。
- **风险**:①拍摄中显示是"暂定版"(内容会细化)——UX 文案要配合;
